1. BLoC Architecture Concept & Setup

BLoC (Business Logic Component) ဆိုသည်မှာ UI မှ ပေးပို့လိုက်သော Events များကို လက်ခံပြီး Business Logic များ တွက်ချက်ကာ UI သို့ States များ ပြန်လည် ထုတ်ပေးသော (Stream-based) စနစ်ဖြစ်ပါသည်။

BLoC ရဲ့ အဓိက အကျိုးကျေးဇူးများ:

  • Predictable States: Event တစ်ခုချင်းစီအတွက် State ဘယ်လို ပြောင်းလဲမည်ကို အတိအကျ စီမံနိုင်ခြင်း။
  • Separation of Concerns: UI ကို အလှဆင်ရန်သက်သက် ရေးသားပြီး Logic အားလုံးကို BLoC Class ထဲသို့ သီးသန့်ခွဲထုတ်နိုင်ခြင်း။
  • Testing: Business Logic သီးသန့်ကို Unit Test ရေးရလွယ်ကူခြင်း။

2. Events & States Definition

BLoC ရေးသားရာတွင် အဓိက အစိတ်အပိုင်း (၂) ခုဖြစ်သည့် Events (UI မှ ခေါ်သော Action) နှင့် States (UI ပေါ် ပြသရမည့် Data) တို့ကို သီးသန့် Class များအဖြစ် သတ်မှတ်ပေးရပါသည်၊၊

အစိတ်အပိုင်းများ:

  • Events: User ပြုလုပ်လိုက်သော Action များ (ဥပမာ - AddTodoEvent, DeleteTodoEvent)။
  • States: UI တွင် ဖြစ်ပေါ်မည့် အခြေအနေများ (ဥပမာ - TodoInitial, TodoLoading, TodoLoaded)။
// 1. ABSTRACT EVENTS abstract class TodoEvent {} class AddTodoEvent extends TodoEvent { final String task; AddTodoEvent(this.task); } class RemoveTodoEvent extends TodoEvent { final int index; RemoveTodoEvent(this.index); } // 2. ABSTRACT STATES abstract class TodoState {} class TodoInitialState extends TodoState {} class TodoLoadedState extends TodoState { final List<String> tasks; TodoLoadedState(this.tasks); }

3. BLoC Class Implementation

Bloc<Event, State> ကို Extends လုပ်ပြီး on<Event> မက္ကနိဇမ်မှတစ်ဆင့် Event တစ်ခုချင်းစီအတွက် emit(NewState) ဖြင့် State အသစ်များကို ထုတ်ပေးရပါသည်၊၊

အဓိက ပါဝင်သောအရာများ:

  • super(InitialState): စတင်ပွင့်ချိန်တွင် ရှိမည့် စာမျက်နှာ အခြေအနေ။
  • on<Event>: ဝင်လာသော Event ကို နားထောင်ပြီး Logic တွက်ချက်ခြင်း။
  • emit(): Logic တွက်ပြီးပါက State အသစ်ကို UI သို့ ပစ်လွှတ် (Emit) ပေးခြင်း။
import 'package:flutter_bloc/flutter_bloc.dart'; class TodoBloc extends Bloc<TodoEvent, TodoState> { final List<String> _tasks = []; TodoBloc() : super(TodoInitialState()) { // Add Todo Event Handler on<AddTodoEvent>((event, emit) { if (event.task.isNotEmpty) { _tasks.add(event.task); emit(TodoLoadedState(List.from(_tasks))); } }); // Remove Todo Event Handler on<RemoveTodoEvent>((event, emit) { _tasks.removeAt(event.index); emit(TodoLoadedState(List.from(_tasks))); }); } }

4. BlocBuilder & BlocListener (UI)

UI ဘက်တွင် BLoC ကို အသုံးပြုရန်အတွက် BlocProvider ဖြင့် Wrap လုပ်ပြီး၊ BlocBuilder (UI ဆွဲရန်) သို့မဟုတ် context.read<Bloc>().add(Event) (Event ပို့ရန်) များကို သုံးရပါသည်၊၊

အရေးကြီးသော Widgets များ:

  • BlocProvider: BLoC Instance ကို Widget Tree ပေါ်သို့ တင်ပေးခြင်း။
  • BlocBuilder: State ပြောင်းတိုင်း UI ကို Rebuild ပြုလုပ်ပေးခြင်း။
  • BlocListener: State ပြောင်းချိန်တွင် Dialog ပြခြင်း၊ SnackBar ပြခြင်းစသော One-time Actions များအတွက် အသုံးပြုခြင်း။
  • context.read<Bloc>().add(): Event အသစ်တစ်ခု ပို့လွှတ်ရန် ခေါ်ယူခြင်း။
// 1. Event တစ်ခု ပို့လွှတ်ခြင်း (Button Press) ElevatedButton( onPressed: () { context.read<TodoBloc>().add(AddTodoEvent(controller.text)); }, child: const Text('Add Task'), ) // 2. State ကို စောင့်ကြည့်၍ UI ဆွဲခြင်း BlocBuilder<TodoBloc, TodoState>( builder: (context, state) { if (state is TodoLoadedState) { return ListView.builder( itemCount: state.tasks.length, itemBuilder: (context, index) => Text(state.tasks[index]), ); } return const Text('No Tasks Available'); }, )
