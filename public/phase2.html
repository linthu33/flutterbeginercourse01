Flutter Phase 2: Navigation & Routing

Page များ အပြန်အလှန် ရွှေ့ပြောင်းခြင်း၊ Data ပေးပို့ခြင်းနှင့် Routing စနစ်များ လေ့လာရန်

1. Basic Navigator (Push & Pop)

Flutter တွင် Screen များကို **Stack (ထပ်လျက်ပုံစံ)** ဖြင့် စီမံပါသည်။ Page အသစ်သို့ သွားလိုပါက Navigator.push() ကို သုံးပြီး၊ မူလ Page သို့ ပြန်ထွက်လိုပါက Navigator.pop() ကို အသုံးပြုပါသည်။

အဓိက ပါဝင်သော မက္ကနိဇမ်များ:

  • Navigator.push(): Screen အသစ်တစ်ခုကို Stack ၏ အပေါ်ဆုံးသို့ တင်လိုက်ခြင်း (Page သစ်သို့ ရောက်ရှိသွားမည်)။
  • MaterialPageRoute: Android/iOS ပုံစံ Slide/Fade Transition Animation များဖြင့် Page အသစ်ဖွင့်ပေးခြင်း။
  • Navigator.pop(): လက်ရှိ Screen ကို ဖျက်ထုတ်လိုက်ပြီး အောက်တွင် ကျန်ရှိသော မူလ Screen သို့ ပြန်ရောက်သွားခြင်း (Back Button)။
// 1. Page အသစ်သို့ သွားခြင်း ElevatedButton( onPressed: () { Navigator.push( context, MaterialPageRoute( builder: (context) => const SecondScreen(), ), ); }, child: const Text('Go to Second Screen'), ) // 2. မူလ Page သို့ ပြန်ထွက်ခြင်း ElevatedButton( onPressed: () { Navigator.pop(context); }, child: const Text('Back to First Screen'), )

2. Passing Data Between Screens

Page တစ်ခုမှ အခြား Page တစ်ခုသို့ Data (ဥပမာ - Username, Product ID, Object) များကို **Constructor သို့မဟုတ် Return Value** မှတစ်ဆင့် ပေးပို့/လက်ခံနိုင်ပါသည်။

Data ပေးပို့နည်း (၂) မျိုး:

  • Forward Passing: Screen A မှ Screen B သို့ Constructor ဖြင့် Data ပါးလိုက်ခြင်း။
  • Backward Passing (Return Result): Screen B တွင် အလုပ်လုပ်ပြီး ရရှိလာသော အဖြေ/Data ကို Navigator.pop(context, result) ဖြင့် Screen A သို့ ပြန်လည်ပေးပို့ခြင်း။
// Screen A မှ Data ပါး၍ ဖုန်းခေါ်ခြင်း Navigator.push( context, MaterialPageRoute( builder: (context) => DetailScreen( userName: 'Aung Aung', age: 25, ), ), ); // Screen B (DetailScreen) တွင် လက်ခံယူခြင်း class DetailScreen extends StatelessWidget { final String userName; final int age; const DetailScreen({ super.key, required this.userName, required this.age, }); @override Widget build(BuildContext context) { return Text('User: $userName, Age: $age'); } }

3. Named Routes

App တွင် Page ပမာဏ များပြားလာပါက Route များကို နာမည်တပ်၍ (ဥပမာ - '/home', '/details') MaterialApp ၏ routes: {} ထဲတွင် စနစ်တကျ စုစည်းသတ်မှတ်ထားနိုင်ပါသည်။

အကျိုးကျေးဇူးများ:

  • Code များ ပိုမိုသန့်ရှင်းပြီး စနစ်တကျ ဖြစ်သွားခြင်း။
  • Navigator.pushNamed(context, '/details') ဟု နာမည်ဖြင့် အလွယ်တကူ ခေါ်ယူနိုင်ခြင်း။
  • initialRoute: '/' ဖြင့် စတင်ပွင့်မည့် Screen ကို သတ်မှတ်နိုင်ခြင်း။
// 1. MaterialApp တွင် Routes သတ်မှတ်ခြင်း MaterialApp( initialRoute: '/', routes: { '/': (context) => const HomeScreen(), '/profile': (context) => const ProfileScreen(), '/settings': (context) => const SettingsScreen(), }, ); // 2. Route Name ဖြင့် Page ရွှေ့ခြင်း Navigator.pushNamed(context, '/profile');

4. Modern Routing: GoRouter Concept

Web Browser URLs, Deep-Linking နှင့် Complex Navigation (Nested Tab Bars) များအတွက် Flutter Official မှ အကြံပြုထားသော go_router package ဖြစ်ပါသည်။

အဓိက အင်္ဂါရပ်များ:

  • URL Path များအတိုင်း သွားလာနိုင်ခြင်း (ဥပမာ - /user/123)။
  • Declarative Routing ဖြစ်သဖြင့် Web URL ကို တိုက်ရိုက်ရိုက်ထည့်ပါက သက်ဆိုင်ရာ Page သို့ ရောက်ရှိခြင်း။
  • Auth State ပေါ်မူတည်၍ Login မဝင်ရသေးပါက Login Page သို့ အလိုအလျောက် Redirect ခိုင်းနိုင်ခြင်း။
// GoRouter သုံးစွဲပုံ (pub.dev မှ go_router လိုအပ်သည်) final GoRouter _router = GoRouter( routes: [ GoRoute( path: '/', builder: (context, state) => const HomeScreen(), ), GoRoute( path: '/details', builder: (context, state) => const DetailsScreen(), ), ], ); // Page ရွှေ့နည်း context.go('/details');

5. Complete Navigation Tutorial Code main.dart

အောက်ပါ Code ကို ကူးယူပြီး သင်၏ Flutter project ထဲရှိ lib/main.dart ထဲတွင် အစားထိုး၍ flutter run ဖြင့် စမ်းသပ်နိုင်ပါသည်။
