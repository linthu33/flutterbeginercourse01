PHASE 1

Layout Core & Basic Widgets

Widget များကို စနစ်တကျ နေရာချခြင်းနှင့် အခြေခံ UI တည်ဆောက်ခြင်း

  • Single-child Layouts: Container, Padding, Center, SizedBox, Expanded, Flexible
  • Multi-child Layouts: Row, Column, Stack (Widget များ ထပ်လျက်နေရာချရန်), Positioned
  • Scrollable Widgets: ListView, ListView.builder, GridView
  • Form Inputs: TextField, ElevatedButton, TextButton, Checkbox, Switch

PHASE 2

Navigation & Routing

Page တစ်ခုမှ တစ်ခုသို့ ကူးပြောင်းခြင်းနှင့် Data ပေးပို့ခြင်း

  • Basic Navigation: Navigator.push() နှင့် Navigator.pop() သုံးစွဲနည်း
  • Named Routes: Route နာမည်များ သတ်မှတ်၍ သွားလာခြင်း
  • Passing Data: Page များအကြား Data/Arguments များ လွှဲပြောင်းပေးပို့ခြင်း
  • GoRouter Package: Web & Mobile နှစ်ခုလုံးအတွက် Modern Deep-Linking စီမံခြင်း

PHASE 3

State Management (BLoC)

App အတွင်း Data ပြောင်းလဲမှုများကို စမတ်ကျကျ စီမံခန့်ခွဲခြင်း

  • Local State: setState() ကို မှန်ကန်စွာ သုံးတတ်ရန် (Widget တစ်ခုစာ)
  • Bloc / Cubit: Enterprise App ကြီးများအတွက် Event-Driven Architecture
  • BlocProvider & BlocBuilder: UI နှင့် Business Logic ကို သီးခြားစီ ခွဲထုတ်ရေးသားခြင်း
  • Events & States: Input Events များနှင့် Output States များ စီမံခြင်း

PHASE 4

Asynchronous & API Integration

Backend Server များနှင့် အင်တာနက်ပေါ်မှ Data များ လှမ်းယူခြင်း

  • Dart Async Basics: Future, async/await, Stream (Live Data များအတွက်)
  • HTTP Clients: http သို့မဟုတ် dio package (Headers, Interceptors)
  • JSON Parsing: API မှလာသော JSON များကို Dart Model Class အဖြစ် ပြောင်းလဲခြင်း
  • Handling States: Loading, Success နှင့် Error UI များကို ကိုင်တွယ်ခြင်း

PHASE 5

Local Data Storage

App ပိတ်လိုက်သော်လည်း ဖုန်းထဲတွင် Data များ ကျန်ရှိနေစေရန် သိမ်းဆည်းခြင်း

  • Shared Preferences: User Settings, Theme, Auth Token များ အလွယ်သိမ်းရန်
  • SQFlite: SQL Database ဖြင့် Data များကို ဇယားလိုက် စနစ်တကျ သိမ်းဆည်းခြင်း
  • Hive / Isar: NoSQL ပုံစံ - အလွန်မြန်ဆန်သော Local Database များ

Native Capabilities & Packages
