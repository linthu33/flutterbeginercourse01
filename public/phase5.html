Flutter Phase 5: Local Data Storage

SharedPreferences, SQLite နှင့် Hive NoSQL စနစ်များဖြင့် Data အမြဲသိမ်းဆည်းထားနည်း

1. Shared Preferences

User Login Token၊ Dark Theme Settings စသော ရိုးရှင်းသည့် Key-Value Data များ သိမ်းဆည်းရန် သုံးပါသည်။

အသုံးများသော Methods များ:

  • prefs.setString('key', 'value'): String သိမ်းရန်။
  • prefs.setBool('key', true): Boolean သိမ်းရန်။
  • prefs.getString('key'): ပြန်လည်ထုတ်ယူရန်။
// Save Data final prefs = await SharedPreferences.getInstance(); await prefs.setString('user_token', 'token_123'); // Read Data String? token = prefs.getString('user_token');

2. SQFlite (SQL Database)

ဇယား (Tables) များဖြင့် စနစ်တကျ ချိတ်ဆက်သိမ်းဆည်းရသော Complex Local Data များအတွက် သုံးပါသည်။

SQL Operations (CRUD):

  • Insert: ဇယားထဲ Data သစ်ထည့်ခြင်း။
  • Query: Data ပြန်လည်ရှာဖွေထုတ်ယူခြင်း။
await db.insert( 'todos', {'title': 'Buy Milk', 'completed': 0}, conflictAlgorithm: ConflictAlgorithm.replace, );

3. Hive / Isar (NoSQL)

Pure Dart ဖြင့် ရေးသားထားပြီး အလွန်မြန်ဆန်သော NoSQL Database ဖြစ်ပါသည်။ SQLite ထက် ၅ ဆခန့် ပိုမိုမြန်ဆန်ပါသည်။

Box Concept:

  • Hive တွင် Database ဇယားများအစား Box များကို အသုံးပြုပါသည်။
var box = Hive.box('myBox'); box.put('name', 'Kyaw Kyaw'); print(box.get('name'));

4. Complete Executable Code (main.dart)

pubspec.yaml တွင် shared_preferences: ^2.2.2 ထည့်သွင်းပြီး အောက်ပါ Code ကို Run နိုင်ပါသည် -
