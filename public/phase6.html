Flutter Phase 6: Native Capabilities & Packages

ဖုန်း၏ Camera, Location GPS နှင့် Device Hardware များကို ချိတ်ဆက်အသုံးပြုနည်း

1. Camera & Gallery Access

image_picker package ကို သုံး၍ ဖုန်း၏ Camera သို့မဟုတ် Photo Gallery မှ ဓာတ်ပုံများ ရယူခြင်း။

အဓိက ပါဝင်မှုများ:

  • ImageSource.gallery: Gallery မှ ရွေးရန်။
  • ImageSource.camera: Camera တိုက်ရိုက်ရိုက်ရန်။
final picker = ImagePicker(); final image = await picker.pickImage( source: ImageSource.gallery, );

2. Device Location (GPS)

geolocator package ကို သုံး၍ ဖုန်း၏ လက်ရှိ GPS Latitude/Longitude တည်နေရာကို ရယူခြင်း။

Location Permissions:

  • iOS / Android permission များကို AndroidManifest.xml နှင့် Info.plist ထဲတွင် တောင်းခံပေးရပါမည်။
Position pos = await Geolocator.getCurrentPosition( desiredAccuracy: LocationAccuracy.high, );

3. Pub.dev Ecosystem

Flutter ၏ တရားဝင် Package ရတနာသိုက်ဖြစ်သော pub.dev မှ စိစစ်ပြီးသား Open-source Packages များကို ရှာဖွေသုံးစွဲနည်း။

အသုံးများသော Packages များ:

  • url_launcher: Web Link သို့မဟုတ် Phone Dial ခေါ်ရန်။
  • flutter_local_notifications: Push Alert ပြရန်။
# Package အသစ် ထည့်သွင်းနည်း flutter pub add url_launcher

4. Complete Executable Code (main.dart)

pubspec.yaml တွင် image_picker: ^1.0.7 ထည့်သွင်းပြီး အောက်ပါ Code ကို Run နိုင်ပါသည် -

import 'package:flutter/material.dart'; import 'package:image_picker/image_picker.dart'; void main() => runApp(const NativeApp()); class NativeApp extends StatelessWidget { const NativeApp({super.key}); @override Widget build(BuildContext context) { return MaterialApp( home: Scaffold( appBar: AppBar(title: const Text('Phase 6: Image Picker Demo')), body: Center( child: ElevatedButton.icon( icon: const Icon(Icons.photo), label: const Text('Pick Image from Gallery'), onPressed: () async { final picker = ImagePicker(); final image = await picker.pickImage(source: ImageSource.gallery); if (image != null) { print('Picked Image Path: ${image.path}'); } }, ), ), ), ); } }
