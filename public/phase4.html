Flutter Phase 4: Asynchronous & API Integration

Backend Server ထံမှ HTTP API Data များ တောင်းဆိုခြင်းနှင့် Model ပြောင်းလဲနည်းများ

1. Async, Await & Future

Network API ခေါ်ယူခြင်းနှင့် Disk ရေးဖတ်ခြင်းများသည် အချိန်ယူရသဖြင့် App မရပ်သွားစေရန် Asynchronous Programming (`Future`, `async/await`) ကို သုံးရပါသည်။

အဓိက သဘောတရားများ:

  • Future: အနာဂတ်တွင် ထွက်ပေါ်လာမည့် Data တန်ဖိုး။
  • async/await: API Data ရောက်ရှိလာသည်အထိ ခေတ္တစောင့်ဆိုင်းပြီးမှ နောက်တစ်ကြောင်းသို့ ဆက်သွားရန် သတ်မှတ်ခြင်း။
Future<String> fetchData() async { // 2 စက္ကန့် စောင့်ဆိုင်းခြင်း await Future.delayed(const Duration(seconds: 2)); return 'Data Loaded Successfully'; }

2. HTTP Request & JSON Model Parsing

http package ကို သုံး၍ API ခေါ်ယူပြီး JSON Response ကို Dart Class Object သို့ ပြောင်းလဲအသုံးပြုခြင်း။

လုပ်ဆောင်ချက် အဆင့်များ:

  • Model Class: JSON Key များကို Dart Property များအဖြစ် စီမံခြင်း။
  • fromJson: Factory Constructor ဖြင့် JSON Map မှ Object သို့ ပြောင်းခြင်း။
class Post { final int id; final String title; Post({required this.id, required this.title}); factory Post.fromJson(Map<String, dynamic> json) { return Post( id: json['id'], title: json['title'], ); } }

3. FutureBuilder Widget

API Data တောင်းနေချိန်တွင် Loading UI၊ Data ရလာပါက Content UI၊ Error တက်ပါက Error UI များကို အလိုအလျောက် စီမံပေးသည့် Widget ဖြစ်ပါသည်။

Snapshot States:

  • snapshot.connectionState == ConnectionState.waiting: Loading ပြရန်။
  • snapshot.hasError: Error တက်ကြောင်း ပြရန်။
  • snapshot.hasData: Data ရလာပါက UI တွင် ဖော်ပြရန်။
FutureBuilder<Post>( future: fetchPost(), builder: (context, snapshot) { if (snapshot.connectionState == ConnectionState.waiting) { return const CircularProgressIndicator(); } else if (snapshot.hasError) { return Text('Error: ${snapshot.error}'); } return Text(snapshot.data!.title); }, )

pubspec.yaml တွင် http: ^1.2.0 ထည့်သွင်းပြီး အောက်ပါ Code ကို Run နိုင်ပါသည် -
