💻 လက်တွေ့ ကုဒ်ဥပမာများနှင့် ရှင်းလင်းချက်များ

1. O(1) - Hash Map (Object) ဖြင့် Data ရှာဖွေခြင်း

Time: O(1)

ရှင်းလင်းချက်: Array လို အစကနေ အဆုံး လိုက်မရှաဘဲ Key ကို အသုံးပြု၍ Memory နေရာသို့ တိုက်ရိုက် သွားရောက် ယူဆောင်ခြင်း ဖြစ်ပါသည်။ 

const usersMap = {
    "u001": { name: "Aung Aung", role: "Admin" },
    "u999": { name: "Zaw Zaw", role: "User" }
};

// O(1) ဖြင့် ချက်ချင်းခေါ်ယူခြင်း
console.log(usersMap["u999"].name); // Output: Zaw Zaw

2. O(log n) - Binary Search (ထက်ဝက်စီ ပိုင်းခြားရှာဖွေခြင်း)

Time: O(log n)

ရှင်းလင်းချက်: စီစဉ်ထားပြီးသား (Sorted) Data များထဲမှ အလယ်ကိန်းကို ယူ၍ လိုချင်သောတန်ဖိုး ကြီး/ငယ်အလိုက် တစ်ဝက်စီ ပယ်ချကာ အမြန်ဆုံး ရှာဖွေပေးခြင်း ဖြစ်ပါသည်။ 

function binarySearch(arr, target) {
    let left = 0, right = arr.length - 1;
    while (left <= right) {
        let mid = Math.floor((left + right) / 2);
        if (arr[mid] === target) return mid;
        if (arr[mid] < target) left = mid + 1;
        else right = mid - 1;
    }
    return -1;
}
console.log(binarySearch([2, 5, 8, 12, 16, 23], 16)); // Output: 4 (Index)

3. O(n) - Linear Search (Loop တစ်ကြိမ်ပတ်ခြင်း)

Time: O(n)

ရှင်းလင်းချက်: Data အရေအတွက် (n) တိုးလာသည်နှင့်အမျှ လုပ်ဆောင်ရမည့် အကြိမ်အရေအတွက်ပါ တိုက်ရိုက် အချိုးကျ တက်လာခြင်း ဖြစ်ပါသည်။ 

const numbers = [10, 20, 30, 40, 50];
const found = numbers.find(n => n === 30);
console.log(found); // Output: 30
