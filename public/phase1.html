Flutter Phase 1: Layout Core & Basic Widgets

အခြေခံ Widget များ၊ Layouts Structure နှင့် Code များကို လက်တွေ့လေ့လာရန် Tutorial

1. Single-child Layout Widgets

Single-child Widgets ဆိုသည်မှာ ကလေး (Child Widget) တစ်လုံးတည်း သာ လက်ခံနိုင်သော Widget များဖြစ်ကြပြီး Size၊ Padding၊ Alignment စသည်တို့ကို စီမံပေးပါသည်။

အဓိက ပါဝင်သော Widgets များ:

  • Container: Margin, Padding, Border, Background Color နှင့် Width/Height သတ်မှတ်ရန်။
  • Padding: Child Widget ကို ဘေးပတ်ပတ်လည်မှ ခြားပေးရန် (EdgeInsets)။
  • Center: Child Widget ကို Screen/Parent ၏ အလယ်တည့်တည့်သို့ ပို့ပေးရန်။
  • SizedBox: အကွာအဝေး (Gap) ခြားရန် သို့မဟုတ် Width/Height အသေ သတ်မှတ်ရန်။
  • Expanded / Flexible: Row သို့မဟုတ် Column ထဲတွင် နေရာအပြည့် ယူခိုင်းရန်။
// Single-child Widgets Example Container( margin: EdgeInsets.all(16.0), padding: EdgeInsets.symmetric(horizontal: 20, vertical: 10), decoration: BoxDecoration( color: Colors.blueAccent, borderRadius: BorderRadius.circular(8), ), child: Center( child: Text( 'Container inside Center', style: TextStyle(color: Colors.white), ), ), )

2. Multi-child Layout Widgets (Row & Column)

Widget များကို ဒေါင်လိုက် (Vertical) သို့မဟုတ် အလျားလိုက် (Horizontal) စီတန်းလိုသည့်အခါ children: [] (List) ကို အသုံးပြုပါသည်။

Row & Column ၏ Alignment များ:

  • Row: အလျားလိုက် စီပေးသည်။ (MainAxis = ဘယ်/ညာ, CrossAxis = အပေါ်/အောက်)
  • Column: ဒေါင်လိုက် စီပေးသည်။ (MainAxis = အပေါ်/အောက်, CrossAxis = ဘယ်/ညာ)
  • MainAxisAlignment: start, center, end, spaceBetween, spaceAround
  • CrossAxisAlignment: start, center, end, stretch
// Row & Column Example Column( mainAxisAlignment: MainAxisAlignment.center, crossAxisAlignment: CrossAxisAlignment.center, children: [ Text('Title Text'), SizedBox(height: 10), // Space Gap Row( mainAxisAlignment: MainAxisAlignment.spaceAround, children: [ Icon(Icons.star), Text('4.5 Rating'), ], ), ], )

3. Stack & Positioned Widgets

Widget များကို တစ်ခုပေါ်တစ်ခု ထပ်လျက် (Overlay) နေရာချလိုသည့်အခါ Stack ကို သုံးပါသည်။ နေရာအတိအကျ သတ်မှတ်ရန် Positioned ကို သုံးပါသည်။

အသုံးဝင်ပုံများ:

  • ဓာတ်ပုံပေါ်တွင် စာသား သို့မဟုတ် Icon ထပ်တင်လိုသည့်အခါ (ဥပမာ - Profile Card)။
  • Notification Badge လေးများကို Icon ၏ ထောင့်တွင် ကပ်တင်ချင်သည့်အခါ။
  • Positioned ၏ top, bottom, left, right များကို သုံး၍ နေရာချခြင်း။
// Stack & Positioned Example Stack( children: [ Container( width: 100, height: 100, color: Colors.grey, ), Positioned( top: 5, right: 5, child: Container( padding: EdgeInsets.all(4), color: Colors.red, child: Text('NEW', style: TextStyle(fontSize: 10)), ), ), ], )

4. Scrollable Widgets (ListView & GridView)

Screen ထက် ကျော်လွန်သော Data များ သို့မဟုတ် List များကို Performance မထိခိုက်ဘဲ Scroll ဆွဲ၍ ကြည့်ရှုနိုင်ရန် အသုံးပြုပါသည်။

ListView vs ListView.builder:

  • ListView: Item နည်းနည်းကို ရိုးရိုးတန်းစီပြရန်။
  • ListView.builder: API သို့မဟုတ် Array မှလာသော Data အများကြီး (1000+) ကို Screen ပေါ်ရောက်မှ Render လုပ်ပေးသောကြောင့် Memory သက်သာစေသည်။
  • GridView.builder: 2 Columns / 3 Columns ပုံစံ ကွက်စိပ်ပြရန်။
// ListView.builder Example ListView.builder( itemCount: 20, itemBuilder: (context, index) { return Card( child: ListTile( leading: Icon(Icons.person), title: Text('User Item $index'), subtitle: Text('Subtitle information'), trailing: Icon(Icons.arrow_forward_ios), ), ); }, )

5. Basic Form Inputs & Buttons

User ဆီမှ Input တောင်းခံခြင်းနှင့် Click နှိပ်သည့် Action များကို တုံ့ပြန်ရန် အသုံးပြုပါသည်။

အဓိက ပါဝင်သော Inputs များ:

  • TextField: စာသားများ ရိုက်ထည့်ရန် (Hint, Border Decoration)။
  • ElevatedButton: အရိပ်ပါသော ပင်မ Button။
  • TextButton / IconButton: စာသား သို့မဟုတ် Icon သီးသန့် Button။
  • Checkbox & Switch: On/Off သို့မဟုတ် Check လုပ်ရန်။
// TextField & Button Example TextField( decoration: InputDecoration( labelText: 'Email Address', border: OutlineInputBorder(), prefixIcon: Icon(Icons.email), ), ), SizedBox(height: 15), ElevatedButton( onPressed: () { // Button click logic }, child: Text('Submit'), )
