Flutter State Management နည်းပညာများ

၁။ Local State (setState)

Local State ဆိုသည်မှာ Widget တစ်ခုတည်းအတွင်း၌သာ သက်ရောက်မှုရှိသော State ဖြစ်သည်။ setState() ကို အသုံးပြု၍ တည်ဆောက်ပြီး ရိုးရှင်းသော အက်ပ်များအတွက် အဆင်ပြေသည်။

ပုံ ၁ - setState အသုံးပြု၍ Widget အတွင်း State ပြောင်းလဲခြင်း

အလုပ်လုပ်ပုံ - User က Action တစ်ခုခုလုပ်လိုက်သည်နှင့် setState() ကိုခေါ်ကာ လက်ရှိ Widget ကို Rebuild လုပ်ပြီး UI အသစ်ကို ချက်ချင်း ပြသပေးပါသည်။

Dart Code ဥပမာ (Local State):


import 'package:flutter/material.dart';

class LocalStateExample extends StatefulWidget {
  @override
  _LocalStateExampleState createState() => _LocalStateExampleState();
}

class _LocalStateExampleState extends State<LocalStateExample> {
  int _counter = 0;

  void _incrementCounter() {
    setState(() {
      _counter++; // State ပြောင်းလဲကြောင်း UI ကို Rebuild လုပ်ခိုင်းခြင်း
    });
  }

  @override
  Widget build(BuildContext context) {
    return Scaffold(
      appBar: AppBar(title: Text('Local State (setState)')),
      body: Center(child: Text('Count: $_counter')),
      floatingActionButton: FloatingActionButton(
        onPressed: _incrementCounter,
        child: Icon(Icons.add),
      ),
    );
  }
}

၂။ BLoC State Technology

BLoC (Business Logic Component) သည် အက်ပ်၏ UI (Screen) နှင့် Business Logic များကို သီးခြားစီ ခွဲထုတ်ထားသော Architecture ဖြစ်ပြီး ကြီးမားသော Project များတွင် အများဆုံးအသုံးပြုကြသည်။

ပုံ ၂ - Event များပေးပို့ခြင်းနှင့် State ပြန်လည်ရယူခြင်း အဆင့်ဆင့် (BLoC Architecture)

အလုပ်လုပ်ပုံ -

  • Event: UI မှ User ၏ လုပ်ဆောင်ချက်များကို (ဥပမာ - Button Click) Event များအနေဖြင့် BLoC သို့ ပို့ပေးသည်။
  • BLoC: ရလာသော Event များကို တွက်ချက်ပြီး၊ API များခေါ်ခြင်း စသည်တို့ကို လုပ်ဆောင်သည်။
  • State: အားလုံးပြီးစီးသွားသောအခါ ရလဒ်များကို State အသစ်များအနေဖြင့် UI ဆီသို့ ပြန်လည်ပို့ဆောင်ပေးပြီး၊ ထိုအခါမှသာ UI က အသစ်ပြောင်းလဲ (Update) သွားသည်။

Dart Code ဥပမာ (BLoC အသုံးပြုခြင်း):


// ၁။ Event
abstract class CounterEvent {}
class IncrementEvent extends CounterEvent {}

// ၂။ State
class CounterState {
  final int count;
  CounterState(this.count);
}

// ၃။ BLoC Logic
import 'package:flutter_bloc/flutter_bloc.dart';

class CounterBloc extends Bloc<CounterEvent, CounterState> {
  CounterBloc() : super(CounterState(0)) {
    // Event ကိုလက်ခံပြီး State ကို UI ဆီ ပြန်ပို့ပေးသည် (emit)
    on<IncrementEvent>((event, emit) {
      emit(CounterState(state.count + 1));
    });
  }
}

// ၄။ UI Code (BlocBuilder ကိုသုံး၍ State ပြောင်းလဲမှုများကို စောင့်ကြည့်ခြင်း)
BlocBuilder<CounterBloc, CounterState>(
  builder: (context, state) {
    return Text('Count: ${state.count}');
  },
)
