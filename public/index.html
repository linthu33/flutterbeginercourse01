⚡ Essential Flutter CLI Commands
1. System & Environment Check
flutter doctor
Flutter SDK, Android Studio နှင့် VS Code စသည့် လိုအပ်သော Setup များ စစ်ဆေးခြင်း။
2. Create New Flutter Project
flutter create my_app
Flutter Project အသစ်တစ်ခု စတင်ဖန်တီးခြင်း။
3. Install Packages (Pub Get)
flutter pub get
pubspec.yaml ထဲတွင် ရေးသားထားသော Packages များကို Download ရယူခြင်း။
4. Add Package Directly
flutter pub add flutter_bloc
Command line မှ Package ကို တိုက်ရိုက် ထည့်သွင်းခြင်း။
5. Run Application
flutter run
emulator သို့မဟုတ် ဖုန်းပေါ်တွင် App ကို စတင် Run ခြင်း။
6. Build Android APK
flutter build apk --release
Android ဖုန်းများတွင် တိုက်ရိုက် Install လုပ်၍ရသော Release APK ထုတ်ယူခြင်း။
7. Build Android App Bundle
flutter build appbundle
Google Play Store ပေါ်သို့ Upload တင်ရန် AAB ဖိုင် ထုတ်ယူခြင်း။
8. Clean Build Cache
flutter clean
Error တက်နေပါက တည်ဆောက်ထားသော Cache/Build ဖိုင်များကို ရှင်းထုတ်ခြင်း။
